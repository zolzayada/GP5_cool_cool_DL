# GP5_cool_cool_DL
# Интеллектуальная система оценки страховых рисков и ущерба автомобилей для классификации страховых случаев

## О проекте

Проект представляет собой систему машинного обучения для сопровождения процессов автострахования.

Решение состоит из двух частей:

* модель прогнозирования вероятности наступления страхового случая на основе табличных данных;
* модель компьютерного зрения для определения степени повреждения автомобиля по фотографии.

Первая модель используется на этапе оформления страхового полиса, а вторая при обработке страхового случая после подачи заявки на выплату.

## Бизнес-задача

Разработать систему, которая позволит страховой компании оценивать вероятность наступления страхового случая на этапе оформления полиса и автоматически определять степень повреждения автомобиля по фотографии при рассмотрении заявок на страховые выплаты.

## Сценарий использования

1. Клиент оформляет страховой полис.
2. Модель прогнозирует вероятность наступления страхового случая.
3. На основе результатов прогноза модели сотрудник принимает решение о дополнительных проверках при оформлении и условиях соглашения.
4. При наступлении страхового случая клиент загружает фотографию автомобиля.
5. Модель компьютерного зрения определяет степень повреждения автомобиля.
6. Результаты используются для поддержки принятия решений по страховому случаю.

## Часть 1. Прогнозирование страхового случая

**Тип задачи:** бинарная классификация.

**Датасет:** Car Insurance Claim Prediction Classification

**Источник:** https://www.kaggle.com/datasets/ifteshanajnin/carinsuranceclaimprediction-classification

Датасет содержит информацию о клиентах, транспортных средствах и параметрах страхования. Целевая переменная отражает факт наступления страхового случая (обратился ли в итоге клиент за выплатой).

Классы:

* 1 - клиент обратился в итоге за выплатой;
* 0 - клиент не обратился в итоге за выплатой.

**Основные файлы:**

* `EDA для табличных данных.ipynb`
* `Модели для табличных данных.ipynb`

## Часть 2. Определение степени повреждения автомобиля

**Тип задачи:** многоклассовая классификация изображений.

**Датасет:** Car Damage Severity Dataset

**Источник:** https://www.kaggle.com/datasets/prajwalbhamere/car-damage-severity-dataset

Датасет содержит фотографии автомобилей с различной степенью повреждений.

Классы:

* `01-minor` — легкие повреждения;
* `02-moderate` — средние повреждения;
* `03-severe` — серьезные повреждения.
